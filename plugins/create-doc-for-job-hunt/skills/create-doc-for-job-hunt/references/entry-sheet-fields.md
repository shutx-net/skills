# エントリーシート (Entry Sheet) フィールド仕様

新卒採用などで企業独自のフォーマットで提出されることが多い書類です。
本スキルでは汎用フォーマットを提供します。

## 1. ヘッダー

| フィールド | 必須 | 例 |
|-----------|-----|-----|
| 書類タイトル | ◯ | 「エントリーシート」 |
| 応募企業名 | ◯ | 株式会社○○ 御中 |
| 応募職種 | △ | 総合職 / エンジニア職 |
| 提出日 | ◯ | 2026年5月10日 |

## 2. 基本情報

| フィールド | 必須 |
|-----------|-----|
| 氏名（漢字） | ◯ |
| 氏名（ふりがな） | ◯ |
| 生年月日 | ◯ |
| 大学・学部・学科 | ◯ |
| 卒業/修了予定年月 | ◯ |
| 連絡先（メール・電話） | ◯ |
| 写真欄 | △ |

## 3. 設問（自由設問）

エントリーシートのコアとなる部分。よくある設問例：

| 設問 | 想定文字数 |
|------|----------|
| 志望動機 | 300〜600字 |
| 学生時代に力を入れたこと（ガクチカ） | 300〜600字 |
| 自己PR | 300〜600字 |
| 入社後にやりたいこと | 200〜400字 |
| 長所・短所 | 100〜300字 |
| 趣味・特技 | 50〜200字 |

各設問は **「設問テキスト + 文字数制限 + 回答欄」** で構成。

## 4. その他

- 資格・スキル
- 学業以外の活動（ゼミ、サークル、アルバイト、インターン）
- 留学経験
- 研究テーマ

---

## レイアウト指針

- **A4 縦** が標準
- 各設問のブロックを明確に区切る
- 設問は太字、文字数制限は薄いグレーで併記
- 回答欄の高さは想定文字数から逆算（例：400字なら 60mm 程度）
- 改ページは設問の途中で起きないよう `break-inside: avoid`
- 余白は左右 15mm 程度を確保

## 必須ヒアリング項目

1. 氏名・基本情報
2. 応募企業名・職種
3. 設問内容（企業ごとに異なるため必ず確認）
4. 各設問の文字数制限
5. 各設問への回答内容
6. 学歴・学業情報
7. その他添付情報（資格・課外活動等）

不足情報は推測せず、ユーザーに必ず確認すること。
特に **設問内容と文字数** はユーザー指定が必須。
