# 履歴書 (Rirekisho) フィールド仕様

JIS規格 履歴書をベースとした標準フィールド構成です。

## 1. ヘッダー

| フィールド | 必須 | 例 |
|-----------|-----|-----|
| 書類タイトル | ◯ | 「履歴書」 |
| 作成日 | ◯ | 令和7年5月10日 / 2026年5月10日 |

## 2. 基本情報

| フィールド | 必須 | 備考 |
|-----------|-----|-----|
| 氏名（漢字） | ◯ | 姓と名の間にスペース |
| 氏名（ふりがな） | ◯ | ひらがな |
| 生年月日 | ◯ | 西暦 or 和暦、年齢を併記 |
| 性別 | △ | 任意（記載しない選択肢も可） |
| 写真欄 | ◯ | 30mm × 40mm の領域を確保（実画像は空欄でも可） |
| 現住所（郵便番号） | ◯ | 〒XXX-XXXX |
| 現住所 | ◯ | 都道府県から記載 |
| 現住所ふりがな | ◯ | ひらがな |
| 電話番号 | ◯ | 固定 or 携帯 |
| メールアドレス | ◯ | |
| 連絡先（現住所と異なる場合） | △ | |

## 3. 学歴・職歴

時系列（古い順）で記載。

| フィールド | 例 |
|-----------|-----|
| 年 | 2018 / 平成30 |
| 月 | 4 |
| 内容 | ○○大学 ○○学部 ○○学科 入学 |

慣例：
- 学歴は中学校卒業から記載することが多い
- 「以上」を最終行に右寄せで記載
- 学歴と職歴のセクションを分ける

## 4. 免許・資格

| フィールド | 例 |
|-----------|-----|
| 取得年月 | 2022年6月 |
| 資格名 | 普通自動車第一種運転免許 取得 |

## 5. 志望動機・自己PR・趣味特技

複数行のテキスト領域。書類によっては以下が分かれる：
- 志望の動機
- 自己PR
- 本人希望記入欄
- 趣味・特技
- 通勤時間
- 扶養家族数
- 配偶者の有無

## 6. 本人希望記入欄

希望勤務地、希望職種、給与等の希望条件を記載。

---

## レイアウト指針

- **A4 縦** を標準とする
- 写真欄は **右上**（30mm × 40mm）
- 学歴・職歴は **横長テーブル**（年 / 月 / 内容）
- 各セクション間は罫線で区切る（japanese-formal）
- フォントサイズは本文 10〜10.5pt
- 行高は 1.5〜1.7em

## 必須ヒアリング項目

ユーザーから以下の情報を取得すること：

1. 氏名（漢字・ふりがな）
2. 生年月日
3. 性別（記載するか含めて確認）
4. 住所・連絡先
5. 学歴（中学卒業以降）
6. 職歴
7. 資格・免許
8. 志望動機
9. 自己PR・趣味特技
10. 本人希望記入欄

不足情報は推測せず、ユーザーに必ず確認すること。
